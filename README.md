# Superstore-Sales-Profit-Analysis
Analysed Superstore sales data in Python (pandas) and found that discounts above 20% lose money on average.
Includes bar charts.
I analysed which factors affect profit.
I have  used VS Code and in that i have used Pandas and Jupyter notebook extension - ipynb.

These are my Key findings: 

1. Furniture sells a lot but keeps only a 2.5% profit margin. The other categories keep about 17%.
2. Tables and Bookcases lose money and also have the highest dis  counts in Furniture".
3. Discounts above 20% lose money on average.
4. Central has the highest discount and the lowest profit.
5. Sales peak from September to December, and February is the weakest month.

Data : Superstore dataset from Kaggle, 9,994 orders.
